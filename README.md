# README / Usage

Bu proje, koyu arka planlı, büyük yazıların göründüğü tam ekran bir Android uygulamasıdır.

Özellikler:
- Tam ekran görünüm
- Hangi derste olunduğunu gösterir
- O dersin / molanın bitmesine kalan süreyi gösterir
- Pazartesi-Perşembe ve Cuma için ayrı program mantığı
- GitHub Actions ile APK üretimi

Yerel geliştirme için:

1. Android Studio 2024+ veya Android SDK kurulu olmalıdır.
2. Projeyi açın.
3. `app` modülünde `Build > Build APK` çalıştırın.

APK üretimi için GitHub Actions otomatik çalışır.
